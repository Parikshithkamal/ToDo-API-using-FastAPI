# ToDo-API-using-FastAPI

This project is a simple To-Do API built using python FastAPI, JWT(Jason Web Tokens) Authentication, Argon2 password hashing, MySQL. In this the database is connected using PyMySQL and I have not used any ORM but I have used SQL queries. This allows us to register, login , authenticate using access tokens create To-Do  task, get To-Do task by id and all tasks at once, update the task and delete the to do task.
